# Conflict Ledger

Everything in the requirements that a human still has to decide. The catalog is
a draft while this table has open rows.

| # | Kind | What | Sources | Affects | Decision needed | Decided |
|---|------|------|---------|---------|-----------------|---------|
| 1 | Contradiction | [The two statements, in a few words each] | [Who or which document said each] | [Row ids, or the use case a rule belongs to] | [The question to answer] | |
| 2 | Suspected duplicate | [The two wordings] | | | [Same thing or two things?] | |
| 3 | Unclassifiable | [The statement] | | | [What was meant] | |
| 4 | Undecided | [The value or choice the material assumes] | | | [The value, and who decides] | |

When a row is decided, write the decision and who made it in the last column,
update the catalog, and keep the row: it is the record of why the catalog says
what it says.
